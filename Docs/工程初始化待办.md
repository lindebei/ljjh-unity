# 工程初始化待办（装完 Unity 后照做）

> 建这份清单的原因：本仓的工程骨架是我在没有 Unity 的机器上手工建的——只有 `Assets/`、`Packages/manifest.json`、`ProjectSettings/ProjectVersion.txt` 三样是"真的"，其余 `ProjectSettings/*.asset` 与全部 `.meta` 要等 Unity 第一次打开时自己生成。
> 关联：[[ljjh-design]] 的 `v0.1开工清单.md` 第一节「装环境」。

## 一、装完 Unity 后第一次打开前（3 分钟）

1. 确认 Unity Hub 里装的版本号，例如 `6000.0.58f1`。
2. 改 `ProjectSettings/ProjectVersion.txt` 为实际版本：

   ```text
   m_EditorVersion: 6000.0.58f1
   ```

   版本号不一致时 Hub 会提示"用其它版本打开/升级"，能开但会多问一次；直接写对最省事。

3. Unity Hub → **Add → Add project from disk** → 选 `D:\ljjh\unity` → 打开。
   - **不要**用 "New project" 建到本目录（目录非空会被拒）。

## 二、第一次打开后立刻做的设置

| 位置 | 设置 | 值 |
| --- | --- | --- |
| Edit → Project Settings → Editor | Asset Serialization | **Force Text** |
| Edit → Project Settings → Editor | Version Control | **Visible Meta Files** |
| Edit → Preferences → External Tools | External Script Editor | Visual Studio 2022 |
| Edit → Project Settings → Player | Api Compatibility Level | .NET Standard 2.1 |
| Edit → Project Settings → Player | Scripting Backend | **Mono**（v0.1 不用 IL2CPP） |
| Edit → Project Settings → Quality | 只留 1 档 | 中等 |

## 三、加包（顺序别反，URP 版本必须跟编辑器版本走）

1. Window → Package Manager → Unity Registry → 装 `Universal RP`（版本由编辑器给出，不要手写版本号）。
2. `Assets/Settings/` 右键 → Create → Rendering → **URP Asset (with Universal Renderer)**，命名 `URP-Battle`。
3. Project Settings → Graphics → 默认管线指向 `URP-Battle`；Project Settings → Quality → 同样指向它。
4. Window → Package Manager → 装 `Input System`（装完会要求重启编辑器）。
5. 提交一次（`git add -A && git commit -m "加 URP + Input System，生成工程默认资产"`）。

## 四、建 v0.1 唯一场景

1. File → New Scene → 选 `Basic (URP)` → Save As `Assets/Scenes/BattlePrototype.unity`。
2. 场景结构照 design 仓 `战斗UI线框与交互规格.md` 的层级：`Canvas (Overlay) / 三兽卡列 / 速度条 / 灵能槽 / 技能盘 / 日志区`。
3. 相机改 Orthographic，钉 16:9。

## 五、UnityYAMLMerge（可选，但建议配）

`.gitattributes` 里 `.unity/.prefab/.asset` 用了 `merge=unityyamlmerge`，需要在仓库里登记驱动，否则冲突时只是退回普通文本合并：

```powershell
git config merge.unityyamlmerge.name "Unity SmartMerge"
git config merge.unityyamlmerge.driver "`"D:/Unity/Editor/Data/Tools/UnityYAMLMerge.exe`" merge -p %O %A %B %A"
```

路径按实际安装位置改（`UnityYAMLMerge.exe` 在 `Editor/Data/Tools/` 下）。
